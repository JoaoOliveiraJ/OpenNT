Zw/Nt · serviços do sistema

As chamadas de sistema do NT (abrir arquivos, ler o Registro, consultar o sistema). As Nt* são as que os programas chamam pela ntdll; as Zw* são a versão para chamar de dentro do kernel.

Exemplos: ZwCreateFile ZwReadFile ZwQuerySystemInformation NtClose
